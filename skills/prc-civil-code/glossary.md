# 核心术语表

**表见代理** — 行为人无代理权，但相对人有理由相信其有代理权时，代理行为可能有效（总则）。  
**不当得利** — 无法律根据取得利益并造成他人损失时产生的返还之债（合同编准合同）。  
**不安抗辩权** — 先履行方有确切证据证明后履行方履行能力显著恶化时，可依法中止履行（合同编）。  
**处分行为** — 直接导致权利设立、变更、转让或消灭的行为；须与基础合同区分。  
**代理** — 代理人在权限内以被代理人名义实施行为，法律效果直接归属于被代理人。  
**代位权** — 债务人怠于行使权利影响债权实现时，债权人依法代位行使。  
**格式条款** — 为重复使用预先拟定、订约时未与对方协商的条款。  
**共同危险行为** — 数人实施危及他人安全的行为且无法确定具体侵权人时的责任形态。  
**居住权** — 为满足生活居住需要，依合同或遗嘱设立的用益物权。  
**监护** — 为无或限制民事行为能力人提供人身、财产及其他合法权益保护的制度。  
**请求权基础** — 支持一方向另一方主张特定法律效果的规范依据。  
**情势变更** — 合同基础条件发生订约时无法预见且非商业风险的重大变化时的再协商与司法变更/解除机制。  
**善意取得** — 无处分权人处分财产时，符合善意、合理价格、公示等法定条件的受让人取得权利。  
**诉讼时效** — 权利人持续不行使请求权达到法定期间后，义务人取得时效抗辩的制度。  
**无因管理** — 无法定或约定义务，为避免他人利益受损而管理他人事务形成的债。  
**无权代理** — 行为人没有代理权、超越代理权或代理权终止后实施代理行为。  
**物权请求权** — 权利人为恢复物权圆满状态而请求确认、返还、排除妨害或消除危险等。  
**相邻关系** — 不动产权利人为生产生活便利依法承担容忍、协助等义务的关系。  
**隐私** — 自然人的私人生活安宁和不愿为他人知晓的私密空间、活动、信息。  
**预告登记** — 为保障将来实现不动产物权而进行的登记，防止未经同意处分影响该请求权。  
**债权人撤销权** — 债务人不当处分财产影响债权实现时，债权人请求撤销该行为的权利。  
**占有** — 对物事实上的控制与支配；占有保护不等同于最终权属确认。
