# 体系适用与检索方法

## 民事法律问题的请求权分析
1. **谁向谁**：列出当事人与法律地位，不先贴道德标签。
2. **请求什么**：给付、返还、停止侵害、确认、解除、赔偿或其他救济。
3. **依据何在**：优先找特别编具体条款，再补充适用总则；合同争议还要先合同通则后典型合同。
4. **构成要件**：逐项写出并对应证据；不要只写结论。
5. **抗辩与阻却**：无效/撤销、履行抗辩、时效、免责、减责、过失相抵等。
6. **竞合与顺位**：比较合同、物权、侵权、不当得利等请求权的范围、举证与法律效果。
7. **程序现实**：管辖、举证责任、保全、鉴定、诉讼时效、执行可能性。

## 规范层级
回答时把依据分层标注：
- **法典正文**：本技能直接覆盖。
- **相关法律**：如消费者权益保护法、个人信息保护法等，应另行核验现行文本。
- **司法解释**：说明名称、文号、施行/修订状态，不与正文混写。
- **指导性案例/类案**：仅说明裁判方法，不把个案结论写成普遍法条。
- **学理观点**：存在争议时并列主要观点，指出实务倾向及不确定性。

## 输出模板
1. 一句话结论（附不确定性）。
2. 争点拆分。
3. 法律依据（准确条号；需要时核对原文）。
4. 要件—事实—证据对照。
5. 对方可能抗辩。
6. 风险与可执行建议。

## 更新边界
《民法典》正文截至本技能生成日未纳入司法解释。凡涉及最高人民法院司法解释、会议纪要、指导性案例或新法衔接，必须在线核验现行版本与施行日期。
