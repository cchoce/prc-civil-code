# 第二编：物权（第205—462条）

## 核心功能
物权编回答“某项物由谁支配、支配到什么程度、变动是否对外生效、冲突时谁优先”。分析重点是权利类型、物权变动公示与第三人保护。

## 适用框架
1. 确定标的是不动产、动产还是权利。
2. 确定请求人主张所有权、用益物权、担保物权或占有保护。
3. 找出基础行为与物权变动：合同是否成立有效；登记或交付是否完成。
4. 检查善意取得、预告登记、异议登记、登记错误赔偿等第三人规则。
5. 选择物权请求权：确认、返还原物、排除妨害、消除危险、修理重作更换恢复原状、损害赔偿。

## 体系地图
- **通则与变动**（第205—239条）：物权法定；不动产以登记、动产以交付为核心公示方法，但法律另有规定除外。
- **所有权**（第240—322条）：国家、集体、私人所有权；业主共有；相邻关系；按份与共同共有；善意取得。
- **用益物权**（第323—385条）：土地承包经营权、建设用地使用权、宅基地使用权、居住权、地役权。
- **担保物权**（第386—457条）：抵押、质押、留置；围绕担保范围、设立、公示、顺位、实现和消灭分析。
- **占有**（第458—462条）：即使未证明本权，也可能获得占有返还与妨害排除保护。

## 高频规则
- 不动产物权变动原则上经依法登记发生效力；合同效力通常不因未登记当然受影响。
- 无权处分不当然导致合同无效；物权能否取得另行判断。
- 善意取得需同时核对善意、合理价格与登记/交付等法定条件。
- 担保冲突不能只看合同日期，应核对登记、交付、占有及具体顺位规则。

## 常见误区
- 把买卖合同成立等同于所有权已经转移。
- 把物业服务争议等同于业主可以拒绝一切共同管理义务。
- 仅凭占有推断最终所有权。

## 示例
一房二卖：分别审查两份合同效力、登记归属、是否存在预告登记及受让人善意；“先签合同者”不必然取得所有权，但可能向出卖人请求违约责任。
