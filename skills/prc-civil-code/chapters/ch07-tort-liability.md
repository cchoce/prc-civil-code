# 第七编：侵权责任（第1164—1258条）及附则（第1259—1260条）

## 核心功能
侵权责任编回答“何种受保护权益因何种行为受损、由谁按何种归责原则承担何种责任”。一般规则与特殊侵权必须同时检查。

## 适用框架
1. 识别被侵害的民事权益和损害类型。
2. 确定行为人、可能的替代责任人和安全保障义务人。
3. 选择归责原则：过错、过错推定或无过错责任。
4. 证明行为、损害、因果关系及主观要件；特殊侵权按特别构成要件调整。
5. 检查免责/减责：受害人故意或过失、第三人原因、自甘风险、自助、正当防卫、紧急避险、不可抗力等。
6. 确定多人责任形态：连带、按份或补充责任，并处理内部追偿。
7. 计算人身、财产、精神损害及惩罚性赔偿等救济。

## 特殊侵权地图
- 责任主体特殊规定1188—1201：监护、用工、网络、教育机构、安全保障义务。
- 产品责任1202—1207；机动车1208—1217；医疗1218—1228。
- 环境生态1229—1235；高度危险1236—1244；动物1245—1251；建筑物物件1252—1258。

## 高频规则
- 民法典第1165条为一般过错责任基础；法律规定推定过错时由行为人反证。
- 安全保障义务人与直接侵权第三人的责任层次不同，补充责任后可能追偿。
- 网络侵权要区分用户、网络服务提供者、通知—转送—必要措施等环节。
- 自甘风险不等于对故意或重大过失侵害的概括免责。

## 常见误区
- 看到损害即推定对方承担责任，跳过因果关系和归责原则。
- 把连带责任当作多人侵权的一般规则。
- 混淆违约责任与侵权责任；竞合时应依据请求权和损害类型选择。

## 示例
顾客在商场被第三人伤害：先追究直接侵权人；再判断商场是否违反合理限度内的安全保障义务。商场成立时通常承担相应补充责任，并可依法向第三人追偿。
