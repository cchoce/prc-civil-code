# 第六编：继承（第1119—1163条）

## 核心功能
继承编处理自然人死亡后的遗产归属与债务清理。核心顺序是确认继承开始、遗产范围、继承人资格、遗嘱/遗赠效力、份额与债务清偿。

## 适用框架
1. 确认死亡时间及相互有继承关系数人死亡先后推定。
2. 分离遗产与夫妻共同财产、家庭共有财产及他人财产。
3. 检查继承人是否丧失继承权、放弃继承，是否存在代位或转继承。
4. 先看遗赠扶养协议，再看遗嘱/遗赠，最后适用法定继承。
5. 审查遗嘱形式、能力、真实意思及是否处分无权处分的财产。
6. 清点、保管、分割遗产并在遗产实际价值范围内清偿债务。

## 关键制度
- **一般规定**（第1119—1125条）：继承开始、死亡推定、继承接受/放弃、继承权丧失与宽恕。
- **法定继承**（第1126—1132条）：继承顺序、代位继承、份额调整、酌情分得遗产。
- **遗嘱继承和遗赠**（第1133—1144条）：多种遗嘱形式、见证人、遗嘱撤回变更及必留份。
- **遗产处理**（第1145—1163条）：遗产管理人、转继承、无人继承遗产、债务清偿及遗赠扶养协议。

## 常见误区
- 把被继承人名下全部财产直接作为遗产。
- 认为公证遗嘱当然优先于最后遗嘱。
- 把继承债务理解为继承人无限承担。

## 示例
老人先后订立多份遗嘱：逐份检查形式与真实意思，处理撤回、抵触内容及最后有效意思表示；同时保留缺乏劳动能力又无生活来源继承人的必要份额。
